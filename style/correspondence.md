# Correspondence

Conventions for a letter, email, or document addressed to one named person -- anything where the
governing test is: "Would I have typed this into an email client, in one sitting, without a build
step?" If the answer is yes, this file applies. If the answer needs a build step (a deck, a
formatted report), use the artifact-type file instead.

Composes with [[style/voice]]. The voice file carries the general voice; this file carries the
adjustments that matter when you are writing to a specific person rather than to an audience.
