# Communication preferences

These govern the conversation, not the artifacts. `style/` governs anything that leaves the repo
and does not cover how you answer me in chat, which is why these live here.

## How to talk to me

- Tone: direct, concise, no filler.
- Default response length: short unless I ask for depth.
- Formatting: prose for reasoning, bullets for lists.
- When unsure, ask one clarifying question rather than guessing.

## How this file grows

This file is read at the start of every interaction by every AI client. Add rules here when you
notice the same correction recurring. Each rule should be one you want applied in *every* session,
not just drafting sessions -- rules that apply only when writing artifacts belong in `style/`
instead.
